# Notification policy

Jon selected Telegram as the primary channel. The bot token and private chat ID are stored locally. Telegram accepted one labelled setup message (message ID 3); Jon confirmed receipt on his phone. The default `config.toml` keeps delivery disabled, and shadow mode cannot send automatic events. Pushover is implemented as an optional adapter and remains unused.

From 28 September 2026, Telegram uses a research-first collector policy. Local matching only shortlists a fresh listing. The seller title must identify the actual book or photographer; names appearing solely in a description cannot qualify. An exact eBay Browse check must confirm the current copy is live and priced within the GBP 150 item cap. GPT-6 Sol then researches whether the actual book and offered copy fit Jon's documentary/street/humanist/socially engaged/portrait/colour collecting interests. A concrete edition or special-copy clue and a checked official book reference are required. Routine reprints, generic anthologies, famous-name mentions, unsupported bargains and uncertain results stay in the dashboard without a phone alert. The daily research limit is 16 jobs; exhaustion means a candidate waits, never an unresearched alert.

Only `RESEARCHED_FIND` events with a supported `PAY_ATTENTION`, `GEM`, or `UNICORN` verdict may reach the phone. The short alert gives the live item price, postage if known, tier and Parr/Badger context where applicable, one reason to look, the edition caveat, the main risk, and the listing link. It does not claim a percentage discount without like-for-like market evidence. The delivery worker rechecks the review, current observation, live availability, price, freshness and owner decisions. Old queued `FAST_LEAD`, `RESEARCH_UPDATE`, publisher and sweep events are suppressed. Imported historical stock is silent. An ambiguous provider result gets at most one later retry, with an explicit possible-duplicate label; a second unknown result stays `DELIVERY_UNKNOWN` for inspection. Provider acceptance is distinct from a phone receipt. No purchase, bid or offer is automated.

All 12 source lanes continue collecting candidates. Publisher and prize discoveries remain in the dashboard. Non-eBay seller pages currently lack an exact live price and availability check, so they cannot trigger the strict book alert until that verification is implemented. Research sweeps run less frequently to reserve most of the 16 daily research slots for actual listings.

The first phone test is a clearly labelled setup message, not a purchase recommendation. Jon confirmed this setup test arrived on his phone. A direct seller-link test is still pending. Quiet hours, emergency acknowledgement and repeat policy remain unconfigured, so no emergency repeats are sent.
